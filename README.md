# Repository for "Towards Explainable Uncertainty Estimation with XAI-Informed Reconstruction Errors".

## Computing Infrastructure
The computing infrastructure consisted of a system running Ubuntu 24.04.3 LTS, equipped with an AMD Ryzen Threadripper PRO 5975WX processor (32 cores), 503 GB of RAM, and an NVIDIA GeForce RTX 4090 GPU.

## Running Instructions
To reproduce the results presented in this paper, execute each *.ipynb* notebook located in the ``notebooks`` folder and modify the seed number in *cur_seed.py* accordingly.
